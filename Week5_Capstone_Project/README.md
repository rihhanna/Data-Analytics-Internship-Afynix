# 📊 Marketing Campaign Analysis

## Project Overview

This capstone project analyzes marketing campaign performance to identify effective campaign types, marketing channels, customer segments, and ROI trends.

## Objectives

- Analyze campaign performance.
- Evaluate marketing effectiveness.
- Compare customer engagement.
- Generate actionable business recommendations.

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Analyses

- Data Cleaning
- Exploratory Data Analysis
- Campaign Performance
- ROI Analysis
- Customer Segmentation
- Correlation Analysis

## Key Findings

- Campaign performance varies by campaign type.
- Marketing channels show different conversion rates.
- Customer engagement differs across segments.
- ROI varies significantly between companies.

## Business Recommendations

- Increase investment in high-ROI campaign types.
- Optimize marketing channels with higher conversion rates.
- Target customer segments with stronger engagement.
- Monitor acquisition costs to improve profitability.
